# Security Policy

## Privacy Model

YouTube音源診断 is designed as a static browser app. Selected media files are
processed locally in the user's browser with ffmpeg.wasm and are not uploaded
by this app.

## Reporting

Please report security or privacy issues through GitHub Issues unless a more
private contact method is provided by the repository owner.

When reporting, include:

- affected URL or commit
- browser and operating system
- steps to reproduce
- whether a file upload or network request was observed

Do not include private media files in public issues. Use a minimal synthetic
sample when possible.
